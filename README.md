# Quant

A dated record of my work toward quantitative trading: problems worked, drills run, and projects built. The commit history shows when each piece was done.

## Layout

| Folder | What goes in it |
|---|---|
| [`log/`](log/) | One short entry per study session, named by date (`2026-11-09.md`). |
| [`probability/`](probability/) | Problems I've solved, with my working. |
| [`mental-math/`](mental-math/) | [`scores.csv`](mental-math/scores.csv): one row per timed arithmetic drill. |
| [`projects/`](projects/) | Standalone code projects, each with its own README. |
